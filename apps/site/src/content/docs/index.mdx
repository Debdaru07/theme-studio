```ts
import { createThemeClient, applyTheme } from '@dts/web';

const client = createThemeClient({ endpoint: 'https://themes.example.com', key: 'pk_demo_acme' });

let dispose = applyTheme(client.current, { mode: 'system' }); // bundled default or cached theme
client.subscribe(({ theme }) => {
  dispose();
  dispose = applyTheme(theme, { mode: 'system' });
});
await client.load(); // then style with var(--dts-color-primary) and friends
```

<section class="lp-section not-content" aria-labelledby="faq">
  <div class="lp-head">
    <p class="kicker">Questions</p>
    <h2 id="faq">Before you adopt it</h2>
  </div>
  <div class="faq">
    <details>
      <summary>What does it cost to run?</summary>
      <p>
        It can run entirely on free tiers: the API on Render, the database on Turso, Theme Studio and these docs on
        Cloudflare. The free API sleeps after about 15 minutes idle, so the first request can take 30–60 seconds.
        Apps keep showing their cached theme meanwhile. <a href="/deploy/">Deploy on free tiers</a>
      </p>
    </details>
    <details>
      <summary>What happens when the API is down or the device is offline?</summary>
      <p>
        SDKs load the cached theme first and only replace it when a newer one arrives. With no cache and no network
        they use a bundled default theme, so the app always renders.
      </p>
    </details>
    <details>
      <summary>Is the publishable key a secret?</summary>
      <p>
        No. A <code>pk_…</code> key is read-only and only returns that client’s published theme, so it is safe to ship
        inside an app. <a href="/api/">Theme API reference</a>
      </p>
    </details>
    <details>
      <summary>Can a client break the agency’s design?</summary>
      <p>
        Client editors can only change their own theme, and agencies can lock tokens so clients cannot change them.
        <a href="/concepts/roles/">Roles and permissions</a>
      </p>
    </details>
    <details>
      <summary>How is accessibility enforced?</summary>
      <p>
        Publishing is blocked when core text/background pairs fail WCAG AA (4.5:1) in light or dark mode. Other pairs
        warn inline. <a href="/concepts/publishing/">Contrast and publishing</a>
      </p>
    </details>
    <details>
      <summary>Am I locked in?</summary>
      <p>
        Theme Studio is open source, and a theme is plain JSON with a published
        <a href="/theme.schema.json">JSON Schema</a>. <a href={REPO_URL}>Source on GitHub</a>
      </p>
    </details>
  </div>
